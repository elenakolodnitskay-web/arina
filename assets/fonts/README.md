DejaVu Sans / DejaVu Sans Bold — используются для генерации PDF (`core/document_files.py`),
потому что встроенные шрифты reportlab (Helvetica и т.п.) не поддерживают кириллицу.

Источник: пакет DejaVu Fonts (https://dejavu-fonts.github.io/), файлы взяты из
дистрибутива matplotlib (`mpl-data/fonts/ttf/`), где они переупакованы под тем же
свободным лицензионным соглашением DejaVu Fonts License — разрешает свободное
использование, изменение и распространение, включая встраивание в документы.
Полный текст лицензии: https://dejavu-fonts.github.io/License.html
