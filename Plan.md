## Блокер верхнего уровня (снят полностью)

Изначально здесь был зафиксирован блокер: разработка Фазы 3 и всего, что от неё
зависит (классификация, задачи, напоминания, summary диалога, документы — фактически
весь продукт, кроме каркаса), заблокирована до тех пор, пока в соседнем проекте
**Aiy** не стабилизирован в проде релей OpenRouter через Cloudflare Worker. До снятия
блокера допускалась только работа над Фазами 0-2.

**Снят для разработки 2026-08-19.** Решение: Арина подключается к OpenRouter напрямую,
собственным API-ключом, без релея и без зависимости от инфраструктуры Aiy. Причина —
независимо проверено (из другой сессии), что `https://openrouter.ai/api/v1/models`
отвечает HTTP 200 напрямую с локального компьютера разработчика, без прокси. Фаза 3
разблокирована для разработки и тестирования — и это подтверждение остаётся верным,
локальная работа весь день шла без проблем.

**Уточнение 2026-08-20, при живом деплое на Beget (см. Фазу 9)**: проверка была
неполной — сделана только с локальной машины, не с реального прод-сервера. С IP
Beget VPS (Россия) `openrouter.ai` отвечает `403 Access denied by security policy`
на любой запрос. Для прод-окружения релей всё же нужен — не из Aiy (проект остаётся
полностью независимым от её инфраструктуры, см. правило ниже), а свой, отдельный.
Собственный Cloudflare Worker-релей не сработал по архитектурной причине (Cloudflare
не даёт обходить через Workers блокировки на других Cloudflare-зонах).

**Решено 2026-08-20.** Свой собственный релей на платформе вне Cloudflare — минимальный
прозрачный HTTP-прокси на чистом Python (`urllib`/`http.server`, без зависимостей),
репозиторий `elenakolodnitskay-web/arina-openrouter-relay` (публичный — приватные
репозитории оказались недоступны для аккаунта из-за экспортных ограничений GitHub,
так же как раньше с основным репозиторием Арины), задеплоен на Render.com (Oregon,
US West — не Cloudflare, не Россия) через `render.yaml` (Blueprint). Проверено с
самого Beget-сервера: `curl` на релей → `200`, реальный вызов `llm/client.complete()`
изнутри прод-контейнера → успешный ответ модели. `OPENROUTER_BASE_URL` в проде
переключён на `https://arina-openrouter-relay.onrender.com/api/v1`, контейнер бота
пересоздан. Ни в коде, ни в инфраструктуре релея нет ничего от Aiy — отдельный
GitHub-репозиторий, отдельный аккаунт Render, ключ OpenRouter передаётся насквозь
через заголовок `Authorization` от самой Арины, в релее не хранится.
Локальная разработка блокером не затронута.
